# Cinema 4D Referenčná tabuľka klávesových skratiek

Tento dokument obsahuje zoznam kľúčových klávesových skratiek Cinema 4D, ktoré musí projekt **CineMod** implementovať pre zachovanie svalovej pamäte používateľov C4D.

---

## 1. Navigácia vo viewporte (Viewport Navigation)

| Klávesová skratka | Alternatíva myšou | Funkcia |
| :--- | :--- | :--- |
| **`1` + ťahanie myšou** | Stredné tlačidlo myši (MMB) | **Pan** (posun pohľadu kamery) |
| **`2` + ťahanie myšou** | `Alt` + pravé tlačidlo myši (RMB) | **Zoom / Dolly** (priblíženie / oddialenie) |
| **`3` + ťahanie myšou** | `Alt` + ľavé tlačidlo myši (LMB) | **Orbit / Tumble** (rotácia okolo záujmového bodu) |
| **`F5`** | Stredné kliknutie na viewport | **Prepnúť 1-pohľad / 4-pohľady** (Persp / Top / Right / Front) |
| **`F1`** | - | Perspektívny pohľad |
| **`F2`** | - | Pohľad zhora (Top) |
| **`F3`** | - | Pohľad sprava (Right) |
| **`F4`** | - | Pohľad spredu (Front) |
| **`S`** | - | **Frame Selected** (vycentrovanie na označený objekt) |
| **`H`** | - | **Frame All** (zobrazenie celej scény) |
| **`A`** | - | Prekreslenie viewportu (Redraw) |

---

## 2. Transformačné a výberové nástroje (Transforms & Selection)

| Klávesová skratka | Funkcia | Popis |
| :--- | :--- | :--- |
| **`Space`** | **Prepnúť posledný nástroj** | Rýchle prepínanie medzi výberom a posledným transformačným nástrojom |
| **`E`** (alebo `4`) | **Move Tool** | Nástroj na posun (aktivuje 3D manipulačný gizmo posunu) |
| **`R`** (alebo `6`) | **Rotate Tool** | Nástroj na rotáciu (aktivuje rotačné kružnice) |
| **`T`** (alebo `5`) | **Scale Tool** | Nástroj na zmenu mierky / škálovanie |
| **`9`** | **Live Selection** | Štetcový výber objektov / polygónov / bodov |
| **`0`** | **Rectangle Selection** | Obdĺžnikový výber |
| **`8`** | **Lasso Selection** | Voľný laso výber |
| **`W`** | **Toggle Coordinate System** | Prepínanie medzi globálnymi (World) a lokálnymi (Object) súradnicami |
| **`L`** | **Enable Axis** | Úprava polohy a orientácie stredovej osi (Pivot / Axis) objektu |

---

## 3. Režimy práce a komponenty (Modes & Components)

| Klávesová skratka | Režim | Popis |
| :--- | :--- | :--- |
| **`C`** | **Make Editable** | Prevod parametrického primitívu na upraviteľný mnohouholníkový mesh |
| **`Model Mode`** | Režim celého modelu | Práca s objektmi ako celkami |
| **`Points Mode`** | Režim bodov | Výber a editácia vrcholov (Vertices) |
| **`Edges Mode`** | Režim hrán | Výber a editácia hrán (Edges) |
| **`Polygons Mode`**| Režim polygónov | Výber a editácia plôch (Faces) |

---

## 4. Modelovanie a editácia (Modeling Tools)

| Klávesová skratka | Funkcia |
| :--- | :--- |
| **`D`** | **Extrude** (vytlačenie polygónov) |
| **`I`** | **Inner Extrude** (vnútorné vtlačenie) |
| **`M ~ S`** | **Bevel** (skosenie hrán / bodov) |
| **`K ~ K`** | **Knife Tool** (rezací nôž) |
| **`K ~ L`** | **Loop / Path Cut** (rez po slučke) |
| **`U ~ S`** | **Optimize** (odstránenie nepoužitých bodov a zváranie) |
| **`U ~ C`** | **Close Polygon Hole** (uzavretie diery v polygónoch) |
| **`U ~ Q`** | **Connect Objects + Delete** (zlúčenie objektov do jedného meshu) |
| **`Ctrl` + ťahanie objektu** | **Klonovanie / Duplikácia** vybraného objektu |

---

## 5. Časová os a animácia (Animation & Playback)

| Klávesová skratka | Funkcia |
| :--- | :--- |
| **`F8`** | Spustiť / Zastaviť prehrávanie vpred (Play / Pause) |
| **`F6`** | Prehrávať vzad |
| **`Shift + F`** | Skok na prvý snímok (First Frame) |
| **`Shift + G`** | Skok na posledný snímok (Last Frame) |
| **`F`** | Skok na predchádzajúci snímok (Previous Frame) |
| **`G`** | Skok na nasledujúci snímok (Next Frame) |
| **`F9`** | **Zaznamenať kľúčovú snímku (Record Active Objects)** |

---

## 6. Všeobecné a renderovacie skratky (General & Rendering)

| Klávesová skratka | Funkcia |
| :--- | :--- |
| **`Ctrl + N`** | Nový projekt / dokument |
| **`Ctrl + O`** | Otvoriť projekt |
| **`Ctrl + S`** | Uložiť projekt |
| **`Ctrl + Shift + S`** | Uložiť ako... |
| **`Ctrl + Z`** | Undo (Krok späť) |
| **`Ctrl + Y`** | Redo (Krok dopredu) |
| **`Shift + C`** | **Commander (Rýchle vyhľadávanie akcie alebo nástroja)** |
| **`Ctrl + R`** | Renderovať aktuálny pohľad (Render Viewport) |
| **`Shift + R`** | Renderovať do Picture Viewera |
| **`Ctrl + B`** | Nastavenia renderu (Render Settings) |
| **`Ctrl + D`** | Nastavenia projektu (Project Settings) |
| **`Ctrl + E`** | Predvoľby programu (Preferences) |
| **`Delete`** / **`Backspace`** | Zmazať vybraný objekt |
